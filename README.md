# Сайт со списком запчастей для ЗИП

Сайт: <https://imnaa.github.io/zipdetals/>
Список запчастей: **[Google Таблица](https://docs.google.com/spreadsheets/d/1kIhsasNJc_ByQAFeM96MynhXWAjgqAsnrTY4PU_g9JM/edit)**

## Как добавить или изменить запчасть

Открыть Google Таблицу, дописать или поправить строку — и обновить страницу сайта.
Всё. Ни HTML, ни GitHub трогать не нужно, сайт читает таблицу при каждом открытии.

### Колонки

| Колонка | Что писать | Обязательна |
|---|---|---|
| `Категория` | Название вкладки, например `Прочее`. Новая категория → на сайте появится новая вкладка | да |
| `Раздел` | Подзаголовок внутри вкладки, например `Подшипники`. Пусто — если не нужен | нет |
| `Наименование` | Название запчасти | да |
| `Код/чертеж` | Номер по каталогу или чертежу | нет |
| `Количество` | Число штук | да |
| `Фото` | Пути к фото через `\|`, например `img/oborudonie/DSC05108.JPG \| img/oborudonie/DSC05109.JPG` | нет |

Номера (`№`) проставляются сами и начинаются заново в каждом разделе — вручную их писать не надо.
Порядок вкладок и строк на сайте = порядок строк в таблице.

### Важно

* **Доступ к таблице должен оставаться открытым на чтение:** Доступ → «Все, у кого есть ссылка» → **Читатель**.
  Если доступ закрыть, сайт перестанет видеть изменения и покажет старый сохранённый список.
* Таблица открыта на чтение всем, у кого есть ссылка, поэтому **не добавляйте в неё то,
  что не должно быть публичным** (закупочные цены, телефоны поставщиков и т.п.) — даже в
  «лишние» колонки справа, которые сайт не показывает.
* Не переименовывайте строку заголовков — сайт ищет колонки по названиям.
* Список берётся с **первого листа** таблицы.

### Фотографии

Файлы лежат в репозитории, в папках `img/<раздел>/`. Чтобы добавить новое фото:
на GitHub открыть нужную папку → «Add file» → «Upload files» → Commit,
затем вписать путь в колонку `Фото`. Несколько фото у одной позиции разделяются знаком `|`.

## Если Google станет недоступен

Сайт автоматически возьмёт резервную копию списка из [`data/parts.csv`](data/parts.csv)
и покажет предупреждение, что данные могут быть не самыми свежими.

Копию полезно иногда обновлять: в Google Таблице Файл → Скачать → CSV,
затем загрузить файл в репозиторий вместо `data/parts.csv`.

Чтобы вернуться к списку в репозитории насовсем или переехать на другую таблицу —
в начале файла [`assets/js/parts.js`](assets/js/parts.js) есть блок «НАСТРОЙКА» с одной строкой `SHEET_ID`.

## Устройство

| Файл | Назначение |
|---|---|
| `index.html` | Страница сайта. Таблиц внутри нет — только `<div id="parts">` |
| `assets/js/parts.js` | Читает таблицу, строит вкладки, таблицы, поиск и окно с фото |
| `assets/css/parts.css` | Стили поиска, вкладок и предупреждения |
| `data/parts.csv` | Резервная копия списка на случай недоступности Google |
| `img/` | Фотографии запчастей |
| `detals.html` | Старая версия страницы, на сайте не используется |

На странице есть поиск по наименованию и коду — он ищет сразу по всем вкладкам
и показывает в скобках у каждой вкладки число совпадений.

> Открывать `index.html` двойным щелчком с диска не стоит: браузер в таком режиме
> запрещает читать резервный `data/parts.csv`. Смотрите сайт по ссылке выше либо
> запустите локально `python -m http.server` в папке проекта.
