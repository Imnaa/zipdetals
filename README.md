# Сайт со списком запчастей для ЗИП

Сайт: <https://imnaa.github.io/zipdetals/>
Список запчастей: **[Google Таблица](https://docs.google.com/spreadsheets/d/1kIhsasNJc_ByQAFeM96MynhXWAjgqAsnrTY4PU_g9JM/edit)**

## Как добавить или изменить запчасть

Открыть Google Таблицу, дописать или поправить строку — и обновить страницу сайта.
Всё. Ни HTML, ни GitHub трогать не нужно, сайт читает таблицу при каждом открытии.

### Колонки

| Колонка | Что писать | Обязательна |
|---|---|---|
| `Категория` | Название вкладки, например `Прочее`. Новая категория → на сайте появится новая вкладка | да |
| `Раздел` | Подзаголовок внутри вкладки, например `Подшипники`. Пусто — если не нужен | нет |
| `Наименование` | Название запчасти | да |
| `Код/чертеж` | Номер по каталогу или чертежу | нет |
| `Цена` | Цена за 1 шт. Можно писать `15000`, `15 000` или `15 000,50` | нет |
| `Валюта` | `RUB`, `USD`, `EUR`, `CNY`… Пусто — значит рубли | нет |
| `Количество` | Сколько штук в наличии. Больше этого числа заказать нельзя | да |
| `Фото` | Пути к фото через `\|`, например `img/oborudonie/DSC05108.JPG \| img/oborudonie/DSC05109.JPG` | нет |

Номера (`№`) проставляются сами и начинаются заново в каждом разделе — вручную их писать не надо.
Порядок вкладок и строк на сайте = порядок строк в таблице.

Если цена не указана, на сайте в этой строке будет прочерк, а в заказе — пометка
«цена по запросу». Если в наличии `0`, позицию нельзя выбрать, она помечена «нет в наличии».

## Цены в разных валютах

Каждая позиция может быть в своей валюте. **Надёжный способ — колонка `Валюта`:**
пишите в ней `RUB`, `USD`, `EUR`, `CNY` (подойдут и `$`, `€`, и слова «евро», «доллары»).
Пустая ячейка означает рубли.

Можно и просто написать валюту прямо в цене — `1500 €`, `$200`, `200 USD`. Но помните,
что Google Таблицы иногда сами форматируют такую ячейку как число и символ валюты при
выгрузке теряется; тогда цена молча посчитается рублёвой. Поэтому для валютных позиций
**лучше заполнять колонку `Валюта`** — она главнее того, что написано в цене.

### Откуда берётся курс

Сайт при каждом открытии подтягивает официальный курс ЦБ РФ на текущую дату и показывает
его строкой над таблицей — только по тем валютам, которые реально есть в списке.

В колонке «Цена» стоит цена в своей валюте, а рублёвый эквивалент считается в колонке
«Сумма» и в итоге заказа. В письме продавцу уходит и валютная сумма, и пересчёт в рубли
с указанием даты курса.

Технически курс берётся не с `cbr.ru` напрямую: сайт ЦБ не разрешает браузеру читать свои
данные с чужого домена. Используется ежедневная выгрузка тех же официальных данных с
`cbr-xml-daily.ru` — адрес задан в начале [`assets/js/parts.js`](assets/js/parts.js)
(`RATES_URL`). Если источник не ответит, список всё равно откроется: цены останутся в своей
валюте, а вместо курса появится пометка, что пересчёт в рубли сейчас недоступен.

## Как посетитель оформляет заказ

1. Отмечает галочками нужные позиции (галочка ставится сама, если менять количество).
2. Стрелками выбирает количество — не больше, чем указано в колонке `Количество`.
3. Под таблицей появляется список выбранного и итоговая сумма — по каждой валюте
   отдельно и общим рублёвым эквивалентом по курсу ЦБ. Выбор сохраняется
   при переключении вкладок и при перезагрузке страницы.
4. Кнопка **«Сформировать письмо»** открывает почтовую программу с готовым письмом:
   получатель `pershin1950@mail.ru`, копия `kolya.romashenko@yandex.ru`, в теме — дата
   и сайт, в теле — дата, время, все выбранные позиции с ценами, итог и место для
   контактов покупателя.

В письмо всегда попадает весь выбранный список целиком.

У очень длинных заказов есть оговорка: часть почтовых программ (заметнее всего
Outlook) обрезает слишком длинные ссылки, а кириллица в них кодируется по
6 символов на букву, поэтому предел достигается быстрее, чем кажется. Сайт
предупреждает об этом под кнопкой. Если список в письме всё же открылся
неполным, кнопка **«Скопировать список»** кладёт его целиком в буфер обмена —
останется вставить в письмо.

Адреса получателей заданы в начале [`assets/js/parts.js`](assets/js/parts.js) —
строки `MAIL_TO` и `MAIL_CC`.

### Важно

* **Доступ к таблице должен оставаться открытым на чтение:** Доступ → «Все, у кого есть ссылка» → **Читатель**.
  Если доступ закрыть, сайт перестанет видеть изменения и покажет старый сохранённый список.
* Таблица открыта на чтение всем, у кого есть ссылка, поэтому **не добавляйте в неё то,
  что не должно быть публичным** (закупочные цены, телефоны поставщиков и т.п.) — даже в
  «лишние» колонки справа, которые сайт не показывает.
* Не переименовывайте строку заголовков — сайт ищет колонки по названиям.
* Список берётся с **первого листа** таблицы.

### Фотографии

Файлы лежат в репозитории, в папках `img/<раздел>/`. Чтобы добавить новое фото:
на GitHub открыть нужную папку → «Add file» → «Upload files» → Commit,
затем вписать путь в колонку `Фото`. Несколько фото у одной позиции разделяются знаком `|`.

## Если Google станет недоступен

Сайт автоматически возьмёт резервную копию списка из [`data/parts.csv`](data/parts.csv)
и покажет предупреждение, что данные могут быть не самыми свежими.

Копию полезно иногда обновлять: в Google Таблице Файл → Скачать → CSV,
затем загрузить файл в репозиторий вместо `data/parts.csv`.

Чтобы вернуться к списку в репозитории насовсем или переехать на другую таблицу —
в начале файла [`assets/js/parts.js`](assets/js/parts.js) есть блок «НАСТРОЙКА» с одной строкой `SHEET_ID`.

## Устройство

| Файл | Назначение |
|---|---|
| `index.html` | Страница сайта. Таблиц внутри нет — только `<div id="parts">` |
| `assets/js/parts.js` | Читает таблицу, строит вкладки, таблицы, поиск и окно с фото |
| `assets/css/parts.css` | Стили поиска, вкладок и предупреждения |
| `data/parts.csv` | Резервная копия списка на случай недоступности Google |
| `img/` | Фотографии запчастей |
| `detals.html` | Старая версия страницы, на сайте не используется |

На странице есть поиск по наименованию и коду — он ищет сразу по всем вкладкам
и показывает в скобках у каждой вкладки число совпадений. Отмеченные позиции
при поиске не сбрасываются.

> Открывать `index.html` двойным щелчком с диска не стоит: браузер в таком режиме
> запрещает читать резервный `data/parts.csv`. Смотрите сайт по ссылке выше либо
> запустите локально `python -m http.server` в папке проекта.
